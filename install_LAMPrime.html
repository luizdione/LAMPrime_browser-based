LAMPrime

Install the LAMP primer designer as an app — runs offline, keeps your sequences on your device.

Instale o desenhador de primers LAMP como aplicativo — funciona offline e mantém suas sequências no seu dispositivo.

If the button is greyed out, use the manual steps for your platform below. Se o botão estiver desabilitado, use os passos manuais da sua plataforma abaixo.

Open LAMPrime in the browser → Abrir o LAMPrime no navegador →

🖥️ Windows / macOS / Linux — Chrome or EdgeWindows / macOS / Linux — Chrome ou Edge desktopdesktop

  1. Click Install app above, or the install icon (a small screen with a down-arrow) at the right of the address bar.
  2. Confirm Install. LAMPrime opens in its own window and gets a Start-menu / Launchpad entry.
  3. It works offline from then on.
  1. Clique em Instalar aplicativo acima, ou no ícone de instalação (uma telinha com seta para baixo) à direita da barra de endereço.
  2. Confirme Instalar. O LAMPrime abre em janela própria e ganha atalho no menu Iniciar / Launchpad.
  3. A partir daí, funciona offline.

📱 iPhone / iPad — SafariiPhone / iPad — Safari iOS

  1. Open this page in Safari (not Chrome).
  2. Tap the Share button (the square with an up-arrow).
  3. Choose Add to Home Screen, then Add. The LAMPrime icon appears on your Home Screen.
  1. Abra esta página no Safari (não no Chrome).
  2. Toque no botão Compartilhar (o quadrado com seta para cima).
  3. Escolha Adicionar à Tela de Início e depois Adicionar. O ícone do LAMPrime aparece na tela inicial.

🤖 Android — ChromeAndroid — Chrome Android

  1. Tap Install app above, or open the ⋮ menu.
  2. Choose Install app / Add to Home screen, then confirm.
  1. Toque em Instalar aplicativo acima, ou abra o menu ⋮.
  2. Escolha Instalar aplicativo / Adicionar à tela inicial e confirme.

No app store, no account, no download of an installer. LAMPrime keeps working with no network after the first visit. Sem loja de aplicativos, sem conta, sem baixar instalador. O LAMPrime continua funcionando sem internet após a primeira visita.
